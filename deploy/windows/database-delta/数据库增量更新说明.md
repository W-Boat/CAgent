# CAgent Windows 数据库增量更新

适用于已部署并能正常启动的 CAgent Windows 站点。脚本会列出当前包的知识库和条目数量。实际增量以目标数据库的预览为准。

1. 在服务器解压更新包，保持目标 CAgent 运行。双击 `Update-Database.cmd`。若未自动定位，输入原 CAgent 安装目录，也就是包含 `data\config.json` 或旧版 `.env` 的目录。脚本从安装目录读取数据库连接，优先使用部署包自带的 Node.js。
2. 输入要更新的库编号，用逗号分隔，例如 `2,5,7`。输入 `ALL` 选择包中所有库，直接回车退出。
3. 核对预览。`add` 是可新增的数量，`existing` 是已有记录，`blocked` 是因资料库已移除或登记冲突而跳过的条数。输入 `ADD` 确认写入。数据库在确认前后发生冲突时，重新打开脚本预览。
4. 如有新增，可在合适的时间重启原站点，让 Agent 重新读取知识索引。对应命令是在原安装目录先执行 `Stop.ps1`，再执行 `Start.ps1`；如使用计划任务部署，使用原有启停方式。

也可在 PowerShell 指定路径进行只读预览：

```powershell
.\Update-Database.cmd -InstallRoot 'D:\CAgent' -PreviewOnly
```

使用 `Update-Database.ps1 -KnowledgeBase <库ID>` 可以为自动化任务明确指定一个或多个库。加 `-PreviewOnly` 只读取预览，加 `-Yes` 按已经指定的范围执行。

更新在一个数据库事务内完成，只向知识库、知识条目和校园导览索引写入缺失记录。已有条目按标识跳过，已移除的资料源保留移除状态。地图和其他站点资源继续使用原安装目录，模型、密钥和系统设置继续使用原数据库中的配置。
