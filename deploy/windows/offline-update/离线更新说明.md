# CAgent 2026.11.25-offline.7 Windows 离线升级

本包用于更新已安装的 CAgent Windows 站点，包含新版前后端和可选的数据库增量。沿用现有运行时、服务启停方式和 PostgreSQL 数据库。

1. 确认原站点正常运行。解压 ZIP 到另一个目录，在原站点系统设置导出备份，或按现有流程备份数据库及私有部署配置。
2. 用原有方式停止 CAgent 前后端。若使用上版 Windows 包，手动运行原安装目录的 `Stop.ps1`；计划任务或服务使用原来的停止方式。
3. 在解压目录执行下方命令。脚本会校验新版文件，保留本地地图和其他已有静态资源，再替换前后端构建文件。终端会打印旧版本文件的位置。

   ```powershell
   powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Update-App.ps1 -InstallRoot 'D:\CAgent'
   ```

4. 按原方式启动。检查网页与登录，然后在「系统设置 → 备份与迁移」确认新功能可用。
5. 如需补齐数据，打开包内 `database-delta`，双击 `Update-Database.cmd` 并指向原安装目录。按清单输入本次要更新的库编号，例如 `2,5,7`。输入 `ALL` 选择全部，直接回车退出。核对预览后输入 `ADD` 确认。脚本只追加所选库的缺失条目。导入后按原方式重启应用，立即刷新知识索引。

回退前后端时，停止站点，将当前 `apps\api\dist`、`apps\web\dist` 改名，并把脚本记录的 `api-before`、`web-before` 分别移回原来的 `dist` 位置。数据库增量采用追加事务，应用文件回退与数据库恢复分别执行。
