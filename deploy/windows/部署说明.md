# CAgent Windows Server 离线部署

安装包自带 Windows x64 Node.js、PostgreSQL、前后端和校园资料。首装创建独立数据库，导入知识库、两校区地图和讲座快照，并生成管理员账号、JWT 密钥和数据库密码。

## 安装与访问

1. 使用 Windows Server 2019 或更新版本的 x64 桌面环境或 PowerShell，给安装目录预留约 2 GB 空间。执行 `tar.exe -xf <安装包文件名>`，进入解压得到的 `CAgent`。建议使用短路径，例如 `D:\CAgent`。可用 `Get-FileHash -Algorithm SHA256` 对照随包的校验值。
2. 双击 `Deploy.cmd` 一键配置、导入并启动。服务器没有桌面时执行 `.\Deploy.cmd`，也可直接运行 `powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Install.ps1`。默认站点为 `http://127.0.0.1:8080`。首次登录凭据见 `data\initial-login.txt`，登录后请修改密码并清除该凭据文件。数据库使用安装目录里的 `data\postgres`。
3. 校园网访问时，首次安装可执行 `.\Deploy.cmd -ListenAddress 0.0.0.0 -SiteOrigin http://服务器地址:8080`，并按部署环境放行网页端口。也可以填反向代理的 HTTPS 域名并继续将程序绑定到本机。API 和数据库一直使用本机回环地址。端口可在首装时用 `-WebPort`、`-ApiPort`、`-DbPort` 指定。
4. `Start.ps1` 与 `Stop.ps1` 可手动启停。需要开机启动时，在管理员 PowerShell 执行 `Register-Startup.ps1`，用内置 LOCAL SERVICE 账户运行。健康检查地址为站点的 `/healthz`，日志在 `data` 目录。可在离线环境直接查看随包校园数据，模型调用和持续采集取决于服务器与各服务的连接。

默认本机首装会额外生成一组 24 小时有效的测试超管和测试学生账号。部署成功后在终端显示，备份副本在受权限保护的 `data\test-accounts.json`。正式管理员仍独立生成。用 `-SkipTestAccounts` 可跳过，面向局域网的专用验收站点可用 `-EnableTestAccounts` 显式启用，也可在后台关闭测试模式。

## 导入 API Key

已有加密包时，可将它命名为 `provider.cagent-keys` 放在 `Deploy.cmd` 旁边。双击部署时会自动识别并提示输入口令。也可执行 `.\Deploy.cmd -KeyBundle D:\secrets\provider.cagent-keys`。安装后可先执行 `Stop.ps1`，再用同一命令导入。重复导入同一供应商密钥会跳过，既有密钥保留。供应商须先在后台存在。

自己制作加密包时，在受限目录复制并填写 `provider-keys.example.json`。`providers` 支持每个供应商多把 Key。`environment` 可按需填写 `DEEPSEEK_SEARCH_API_KEY`、`DEEPSEEK_VOICE_API_KEY` 或 `TAVILY_API_KEY`。在安装目录执行：

```powershell
powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Protect-Keys.ps1 -InputJson D:\secrets\provider.json -OutputBundle D:\secrets\provider.cagent-keys
```

加密包与口令分开交付，导入后在「模型供应商」检查掩码并试连。真实 Key 和现用服务器配置通过独立加密包交付。备份或迁移时，需要成套备份数据库和 `data\config.json`，后者包含数据库凭据和解密主密钥。

## 用导出的备份一键恢复

在源站用超管打开「系统设置 → 备份与迁移」，设置口令并导出 `.cagent-backup`。将它命名为 `restore.cagent-backup`，放到新安装包的 `Deploy.cmd` 旁边。双击同一个脚本，输入备份口令，脚本会在创建独立数据库后直接还原备份、启动站点并检查健康状态。也可用 `Deploy.cmd -RestoreBundle <路径>` 指定文件。首装以备份里的资料和设置为准，管理员账号由新站首次创建。

单独部署随包资料时，直接双击 `Deploy.cmd` 即可。已有站点换另一份备份时，通过「系统设置 → 备份与迁移」预览后确认恢复。

该文件迁移已挂载或已停用的知识库、讲座、校园地图原图与标注、供应商及数据库内密钥、模型、智能体、技能和系统设置。相同标识的记录覆盖，包外记录保留，地图按包整体替换。账号、对话、日志以及 `data\config.json` 里的服务器级凭据按目标环境微调或另行迁移。已有数据库的同机版本更新仍应保留整份 `data` 目录。
