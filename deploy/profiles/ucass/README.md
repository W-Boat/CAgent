# 校园应用初始化包

这是 2026-10-12 当前应用的公开内容与配置快照，导入后恢复知识分类、启停、快捷入口、共享 Agent 提示词与技能绑定，以及检索、缓存、输出和主题设置。由生产数据按字段白名单导出，非数据库备份。

| 内容 | 数量 |
|---|---:|
| 内嵌知识索引（含旧版兼容行） | 28,985 |
| 资料库配置 | 39 |
| 已审核发布的外挂条目与关键词规则 | 39 |
| 共享 Agent / 技能 | 4 / 7 |
| 设置 / 模型参数 / 供应商元信息 | 55 / 17 / 9 |

`manifest.json` 包含导出时间、数量、文件大小和 SHA-256。`configuration.json` 保存公共配置，`items-*.json` 为知识分块，每个文件最多1000行，支持普通 Git 下载。

## 导入

先按仓库部署说明配置自己的数据库和密钥、应用迁移并首次 seed 管理员。命令从仓库根目录执行：

```sh
npx pnpm@11.8.0 campus:check
npx pnpm@11.8.0 campus:init
```

Docker：

```sh
docker cp deploy/profiles/ucass cagent-api:/tmp/ucass-profile
docker compose exec api node scripts/import-campus-profile.mjs /tmp/ucass-profile
docker compose exec api node scripts/import-campus-profile.mjs /tmp/ucass-profile --apply
```

默认先验证完整性；`--apply` 才写入。数据在一个事务中导入，失败回滚。默认要求没有知识资料和聊天记录；首次导入会更新 seed 生成的默认设置和共享 Agent，使用自己的管理员作为维护者，原供应商密钥及已配置接口保留。`{{SITE_ORIGIN}}` 自动替换为自己的站点域名。

成功记录 `deployment_profile:ucass-campus` 标记，重复执行直接跳过，管理员后续修改保留。不提供自动覆盖已导入配置的按钮。已有库确需追加时先备份，显式使用 `--allow-existing`；同标识资料保留，不删除原数据。不要把首次初始化当作日常升级命令。

可选择包中已定义的模型作为默认模型：

```sh
node apps/api/scripts/import-campus-profile.mjs deploy/profiles/ucass --apply --model deepseek/deepseek-chat
```

模型选择只在首次初始化有效；之后在后台修改默认模型。调用需要自己的密钥和供应商支持的模型名称。可通过 `PROFILE_PROVIDER_DEEPSEEK_BASE_URL` 等变量配置自己的兼容接口地址，也可在后台维护。

## 范围和部署后的检查

资料包含校园办事、通知、学生手册、经验资料、地图索引及2.0赛事内容。按当前挂载状态导入，2.0模拟内容保留关闭；启用前确认模拟数据适用范围。共享 Agent 的启用状态也保持当前配置，退役社论/情侣功能不包含。

外挂条目仅含已审核发布的正文、规则和摘要，不含草稿、修订历史、来源会话、审核人或命中计数。源资料的校内联系信息属于资料正文，保留来源和时间；使用时以最新正式通知为准。

部署后在知识中心检查库列表与按钮，测试校园位置、办事流程、餐饮规则和来源显示。在「系统设置」检查主题、检索深度、缓存与记忆/引导开关，再用自己的有效模型测试生成式排版。

外部数据库和公众号连接需重新配置，补齐前保持关闭。公众号只提供订阅名称，登录会话、接口地址、凭据和采集器内部账号ID不移植。模型供应商只提供名称、类型和能力参数，私有接口地址/密钥不包含；原有官方默认接口来自源码内的公开预设。

本包不包含账户、密码、个人课表、个人记忆、聊天、反馈证据、用户用量、运行缓存、真实服务端地址或密钥。生成式回复的质量及速度取决于部署者的模型和基础设施；资料、配置与界面行为可按上述步骤恢复。

## 验证

```sh
npx pnpm@11.8.0 campus:verify
```

仅允许本地 PostgreSQL，在独立 schema 执行全部迁移、导入完整快照，验证卡片规则/快捷入口、模型绑定、库开关、链接替换、密钥保留和重复导入保护；结束后清理自身 schema，不调用外部模型。
