资料由用户于 2026-10-11 提供；原刊物发布日期未注明。以下为校园生活经验资料，涉及班车、开放时间、预约及医疗服务时保留原文口径，查询现行安排以对应平台通知为准。

# 一、出行通勤

1. 望京校区离望京南地铁站C口比较近。离良乡校区最近的地铁站是广阳城站，学校安排了摆渡车往返学校与广阳城站A口，发车时间可在“中国社科大移动校园—公共服务—班车服务”查到。摆渡车非常准时，到点即走，建议大家提前几分钟去候车哦。
2. 良乡校区同学早高峰坐地铁，7点前出发人少些。从首经贸站返校时要想有座，可先反向坐一站至东管头南站（始发站）再折返。
3. 工作日7点，望京校区有班车前往良乡校区，车程约80分钟。如需坐地铁，可以选择“14号线—16号线—房山线”或“14号线—9号线—房山线”两条路线，换乘少、空座多。经10号线至首经贸站转房山线也可，但早高峰较拥挤。
4. 研究生的部分专业课会安排在社科院及下属各研究所。去上课时不妨试试从良乡站坐“小火车”到北京站。不用像地铁那样换乘，还能保证有座，路上也能休息一下。

# 二、餐饮采购

1. 良乡校区食堂11:20与12:10下课后是用餐高峰，望京校区11:00与11:50下课后人也很多，建议错峰用餐。工作日晚饭时间，教工食堂对学生开放，可以去尝尝烤鱼和小火锅。
2. 食堂菜单每周都会在微信公众号上提前公布，良乡校区可关注“中国社科大学生会”获取每周菜单，关注“社科汇”小程序获取每日最新菜单。望京校区请关注“社科大望京校区”。

# 三、选课学习

1. 选课，记得先看培养方案。培养方案外的课程若只是感兴趣，不妨旁听。有留学需求的同学，千万别随意选课后旷课或中途放弃，小心影响全科绩点。
2. 如果想抢热门课程，可以在选课系统开放前半小时登录系统持续刷新。选课前要完成教学评教，才能顺利选课。
3. 良乡校区图书馆座位需提前预约，每日12点后可预约次日座位；研讨室须两人或两人以上才能预约，可提前三天，每日9点开放预约。望京校区图书馆无需预约。
4. 良乡校区图书馆座位暂离时间只有1小时，10:50—12:30、16:50—18:30为用餐时段，暂离时间延长到2小时。两校区图书通借通还，预约借阅的图书每周三送达望京校区取书点。
5. 社科大在校生可凭学生证进入社科院及下属科研机构。

# 四、运动锻炼

1. 良乡校区体育馆羽毛球、篮球等场地每日8:00开放预约，热门时段很快约满；操场每日22:50熄灯，夜跑或晚间锻炼记得留意时间。
2. 望京校区设有羽毛球场、排球场、五人制足球场、篮球场及乒乓球室等。乒乓球室每日22点关闭，其他室外场地约23点熄灯；周边公园也适合跑步、散步。
3. 如果对某项运动感兴趣，即使没有抢到对应的体育课，也可去旁听。

# 五、宿舍起居

1. 宿舍隔音效果有限，聊天、打电话时记得控制音量哦。
2. 吹风机每晚11点断电，推荐早点去用，避开断电前的高峰期。
3. 暑假北京比较潮湿，离校时别忘了多放些除湿袋。

# 六、天气健康

1. 北京春季常有沙尘和飘絮。空气质量不好时，长时间在户外记得戴好口罩。晾衣服时要小心沙尘和降雨同时出现，衣服一淋湿就会沾上泥点子。
2. 北京风大，尤其是七号楼与快递点交界处有个风口。选伞时，抗风性能比轻便更重要。

# 七、便捷服务

1. 两校区文件传递柜分别在良乡校区北综合楼一楼和望京校区行政楼一楼，在“中国社科大移动校园”平台就可以办理跨校区文件传递。
2. 校医务室能处理常见疾病，需要转诊的话，凭医务室开的转诊单去定点医院就行。望京校区的定点医院是望京医院和华信医院，良乡校区的是良乡医院与北京医院。
3. 如果在学校里遇到问题，可以通过“中国社科大移动校园—接诉答询”平台反馈。“办好说清”栏目里会定期发布典型诉求案例，方便大家查阅。也可以加校学生会权益部官微“权小益”直接反映。望京校区每学期还会办师生座谈会，可以和校区管理部门当面聊聊。
4. 在“中国社科大移动校园—公共服务—办公电话”栏目里，可以查到学校各部门、各学院的联系方式。

# 用户补充：建筑别名与服务

良乡校区的研教楼即为教学楼；综合楼、新综楼都是教学综合楼，或称教综楼；北综楼有瑞幸。
