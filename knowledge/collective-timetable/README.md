# 集体课表知识库

个人课表、浏览器扩展采集和个人提醒已移除。集体课表是全校公开课程安排快照，不包含用户选课或登录会话；历史数据库表保留，不删除用户历史数据。

在能够访问学校教务网的电脑上运行（Node.js 20 或更新版本）：

```sh
node apps/api/scripts/fetch-collective-timetable.mjs --source=http://campus-teaching-host --output=collective-timetable.json
```

脚本用普通 HTTP 请求先读取全部课程页面及当前学期，再调用页面本身的查询接口。无需学校账号、LLM 或浏览器。临时 HTTP 会话仅用于本次采集，不写入 JSON；导出只保留课程、院系、授课教师姓名、上课时间和教室等教学资料，排除教师工号和选课人数。

在管理端「知识库」点击「上传集体课表」选择导出的 JSON，确认后生成独立内嵌库及绑定快捷按钮。首次导入自动挂载；同学期重复导入更新原条目，保留开关和自定义按钮。关闭知识库后停止检索并隐藏对应快捷按钮，已移除的库不会被刷新复活。仅接受标记 `complete: true` 的完整学期快照，不能用筛选结果覆盖全校资料。

管理员也可调用鉴权接口 `POST /api/knowledge/collective-timetable/import`，权限为 `campus:admin`。CLI 可通过 `--upload=https://your-site.example` 和 `--token-file=/private/admin-token.txt` 上传；访问令牌不要提交到仓库。学校会话不会发送给应用服务器。最大文件 1.9 MB、最多 5000 条安排，默认当前学期，可用 `--semester-id=ID` 选择页面提供的其他学期。

支持「全校课表」「历史哲学课程安排」「第3周周四下午有哪些课」等问题。星期、周次、时间必须命中同一个上课安排；不自动猜测当前教学周。课程号/课序号支持明确筛选。检索返回排名靠前的有限结果，并非将全校全部安排塞入模型上下文。

仓库提供 `catalog.json` 作为 2026-2027 学年第一学期初始快照：666 条课程安排，导入后形成 667 条知识条目（含学期总览）。部署后可直接在管理端上传该文件，再按实际教务变更重新采集更新。快照不是实时教务数据，课程调整、空教室、用户实际选课等应以学校系统为准。应用服务器无需访问校园内网，能访问学校网络的电脑采集后上传即可。
