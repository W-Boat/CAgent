# 校园讲座快照

初始数据来自用户提供的“社科大讲座聚合-仓库导出.zip”中的 `data/lectures.json`，原始生成日期 2026-10-26。保留 1,189 条讲座/活动记录和 18 个来源元数据；未发布原包的独立网页、账号平台入口列表或其 GitHub Actions。本文档及 CAgent 采集实现属于本项目集成说明，不声明这些讲座正文由 CAgent 创作。

日期、时间、地点和主讲人由原来源页面提取，可能缺失或需要核对。数据含历史回顾，不是当前可报名活动清单。前端按当前上海日期计算待开展预告，忽略快照中静态 `meta.upcoming` 计数。具体活动、转载及后续使用以原文和部署方取得的权限为准。

导入和可配置采集见 [讲座功能说明](../../docs/lectures.md)。不会在 API 启动时自动覆盖数据库；首次导入需显式执行脚本或在后台上传。
