# 校园讲座知识库与公开网页采集

`/lectures` 提供讲座月历、列表、校区/来源/预告与回顾筛选、主题搜索、原文阅读与单条 `.ics` 下载。登录用户可阅读；具有 `campus:admin` 权限的管理员可导入、测试和配置采集。学生聊天侧栏提供日历入口，知识库后台也提供入口。

## 初始资料

`knowledge/lectures/lectures.json` 来自提供的讲座聚合导出包，包含 1,189 条资料，来源涉及 18 个校院网站，原始生成日期为 2026-10-26。资料覆盖多年历史，不能将记录总数当成未来活动数量。日历仅按 `event_date` 排入活动，发布日期另行保留；无日期的资料单列。原资料中的抽取日期未逐条人工核验，界面保留核对原通知的提示。

先完成常规部署、数据库迁移和 API 构建，再显式导入：

```sh
pnpm --filter @cagent/api build
pnpm --filter @cagent/api exec node scripts/import-lectures.cjs ../../knowledge/lectures/lectures.json
```

也可以在“知识库管理 → 讲座采集与日历 → 采集与导入”上传该 JSON。页面分批上传，进度表示已完成的导入批次；中断后可重新上传。接口 `POST /api/lectures/import` 每批最多 200 条，页面每批 50 条。Docker 部署可先把 JSON 复制进 API 容器，再执行同一脚本；示例容器名为部署方的 API 容器：

```sh
docker compose cp knowledge/lectures/lectures.json api:/tmp/lectures.json
docker compose exec -T api node scripts/import-lectures.cjs /tmp/lectures.json
```

首次创建独立内嵌库“校园讲座聚合库”，默认挂载；重复导入按来源 URL 合并，不恢复管理员关闭或移除的库，不删除本次未获取的历史文章。仅新增/实际内容改变时刷新知识索引修订；相同资料重复导入不刷新回答缓存。无需新增数据库迁移，结构字段保存在现有知识条目的 JSON 附加字段中，正文沿用现有 RAG 检索和来源体系。

## 采集方式

实现参考导出包的“列表发现 → 详情解析 → 来源去重”流程，使用已有的 Cheerio 和 Node HTTPS，无需安装额外 Python 运行环境。附带 35 个栏目配置，管理员可逐项启停、修改名称/链接、选择全部条目或讲座关键词过滤，也可新增栏目。

- 可配置自动开关、60–10080 分钟间隔、每栏目 1–5 页、每次 1–100 篇有效文章；自动采集默认关闭。保存配置后生效，测试可使用未保存配置。
- 测试仅采集所选栏目的最多 3 篇详情，不写入知识库；正式采集在后台运行，状态持久化在独立库，页面每 5 秒读取运行状态。单次最多 100 次请求，约 150 秒采集预算；测试约 25 秒。
- 校园官网采用思博/VSB 常见列表和正文结构；站点改版、动态渲染、图片海报或访问验证可能导致缺项，未实现 OCR 或绕过访问限制。公众号只尝试读取官网链接到的公开文章，不代替公众号订阅采集器。
- 默认仅支持学校域名与微信公众号的 HTTPS 公共地址，每次重定向重新校验，限制大小与时长，并连接经过检查的 DNS 地址。配置“校园网直连”后，仅允许学校域名解析至 `10.27.0.0/16`；仍拒绝回环、链路本地和其他私网地址，不修改系统 DNS。部署环境需自行具备对应网络连通性。
- 失败或空结果保留旧数据，不把失败当成“清空知识库”。文章身份按 URL 稳定生成；不采用相近标题前缀强行合并，避免误合并不同场次。
- 定时采集按保存配置的管理员身份检查权限；管理员停用或失去权限后停止自动执行。关闭/移除讲座库后停止定时采集，并同步关闭日历、详情和 Agent 检索。

任务执行于单个 API 进程，数据库互斥防止并发启动。重启中断的任务不会自动续跑，过期运行锁约 10 分钟后可重新启动；已导入内容保留。活动资料是快照，不能承诺实时取消通知、报名资格或座位。

## 验证

```sh
pnpm --filter @cagent/api exec ts-node --transpile-only scripts/verify-lectures.ts
node apps/api/scripts/verify-lectures-ui.mjs
```

数据库验证仅允许本地 PostgreSQL，在独立临时 schema 中执行并清理自身夹具，涵盖全量导入、重复幂等、补全、坏批次、检索和停用联动；不会调用模型。可加 `--live` 测试一个学校公开栏目，网络可用性与静态断言结果分别报告。前端验证拦截 API 为合成数据，覆盖管理员/学生、月历/列表、日期选择、详情、导入、配置、日历下载与手机明暗主题。公开发布包不包含登录会话、生产地址或密钥。
